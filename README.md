# homebrew-tap

Homebrew formulae for misorafa tools.

## kioku

Self-hosted, Japanese-first shared memory for AI coding agents — https://github.com/misorafa/kioku

```sh
brew install misorafa/tap/kioku
kioku setup            # or paste the line `kioku invite` prints on your server
```

`Formula/kioku.rb` is written by the kioku release workflow on every stable release; do not
edit it here.
